This project, developed for HealthGuard Analytics Pvt. Ltd., provides a data-driven analysis of an infectious disease outbreak to assist public health authorities in strategic decision-making. By leveraging a Python-based tech stack—including Pandas, Matplotlib, Seaborn, and Scikit-Learn—the system transforms raw patient records into actionable visual and statistical evidence. The core of the study focuses on Demographic Profiling, which identifies high-risk age and gender groups, and Regional Impact Mapping, which pinpoints geographical hotspots to optimize the deployment of medical resources and testing kits.
The analytical workflow incorporates Feature Engineering to calculate the recovery_duration for each patient, establishing a critical benchmark for hospital bed management. To move beyond descriptive statistics, the project implements a Linear Regression model that evaluates how variables like age and contact exposure influence the time taken for a patient to be released. The final output provides a comprehensive report featuring an R-Squared (R^2) score to quantify predictive accuracy, ultimately offering a robust framework for predicting recovery trends and managing future healthcare capacity.
